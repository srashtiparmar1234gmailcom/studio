# **App Name**: Shred Track

## Core Features:

- User Authentication: Secure user sign-up, login, and logout functionality.
- Membership Purchase: Users can purchase hourly, weekly, or monthly membership plans via QR code payment.
- Attendance Calendar: Display a calendar view showing past visits and remaining membership days. The number of remaining days is calculated dynamically based on how many days attendance was recorded.
- Admin Dashboard: Overview of total users, active memberships, today’s attendance, and expiring memberships.
- User Management: Admin can view and manage all registered users, including their details, attendance history, and remaining membership days.
- Attendance Management: Admin can manually mark user attendance, deducting one day from their membership.
- AI-Powered Trend Analysis and Prediction Tool: Generative AI provides insights to help manage attendance. Using attendance patterns and membership data, the tool provides the admin with proactive membership management recommendations.

## Style Guidelines:

- Primary color: Electric Blue (#7DF9FF) to convey a modern and energetic feel, resonating with the skateboarding culture. This is the color that appears most often on the screen, and helps communicate the play park's energetic brand
- Background color: Dark navy (#191970) for a sophisticated contrast, making the vibrant elements pop and reduce eye strain. This complements the primary color without overwhelming it.
- Accent color: Bright Magenta (#FF00FF) to highlight key interactive elements, drawing users’ attention to calls to action and important information.
- Body and headline font: 'Space Grotesk' (sans-serif) for a modern, tech-forward aesthetic that suits a digital platform.
- Code font: 'Source Code Pro' for displaying code snippets related to QR codes and payment processing.
- Use minimalistic, custom-designed icons to represent membership plans, attendance, and admin controls.
- Incorporate subtle transitions and animations when navigating between dashboard sections and updating attendance records.
